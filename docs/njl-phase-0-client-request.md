# NJL Phase 0 — short client request

Good afternoon, Ma'am Louise!

To finalize the inventory and production workflow before rollout, may we ask
for the following available items:

- Two or three completed jobs with the materials planned and actually used.
- Current material/stock list, including unit, quantity on hand, and usual
  pack or roll size.
- Any sample receiving, purchase, material issue, return, waste, or correction
  records—even photos, Excel files, or chat screenshots are okay.
- Confirmation of who can release a job, receive/issue stock, approve waste or
  corrections, and approve purchase requests.
- Confirmation of what allows production to start: customer approval,
  downpayment, layout/sample approval, or owner approval.

No need to organize everything perfectly. A single Google Drive folder is
enough. We will use the records only to map and confirm the actual workflow
before loading real stock or enabling the workflow for production use.
